Shared Responsibility Model
09 - Shared Responsibility - Both Parties Have Skin in the Game

If sales miss target, both parties share the cost burden

This is not a one-sided deal. If Sara does not reach the revenue target, Sara bears the Azure cloud infrastructure cost. Bytewise continues to bear development and support costs. Both parties are financially motivated to hit the target.

"A true joint venture means both sides invest. Sara pays cloud when sales are low. Bytewise pays development always. Together we win."
How the Cost Split Works

Sara Pays (If Sales Below Target)

  • Azure Cloud Infrastructure - as per actual Azure billing
  • Base hosting: Rs.75,000/month (App Service, CDN, SSL, monitoring)
  • Dynamic cloud: Visitors x Rs.1.20 (API calls, bandwidth, DB operations)
  • Total Azure bill: Rs.75,000 + (Visitors x Rs.1.20)
Example: At 48,000 visitors, Sara pays Rs.75,000 + Rs.57,600 = Rs.1,32,600/month

Bytewise Pays (Always)

  • Development and Enhancements - Rs.75,000/month
  • L1 + L2 Support - Rs.80,000/month
  • DevOps, CI/CD, Data, Analytics - Rs.50,000/month
  • SEO/GEO, Security, DB Management - Rs.80,000/month
Bytewise bears: Rs.2,85,000/month in dev + support costs regardless of sales performance
