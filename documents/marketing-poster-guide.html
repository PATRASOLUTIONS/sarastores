1. Which admin page should I use?

For a poster on the current homepage, start at /admin/listing-banners. For a campaign sent to customers, use /admin/customer-centric. To create a destination with a banner and selected products, use /admin/campaign-pages.

A poster is not a discount or a customer message. Banner artwork changes presentation. Coupons change eligible checkout pricing. Email and WhatsApp campaigns contact selected customers. A landing page gives your poster a destination. Set up each required part separately.

Existing tools that should not be mistaken for current homepage controls

/admin/advertisements and /admin/product-advertisements have image/link/active/order forms. However, their older display components are not rendered by the current homepage or current /products page. The category advertisement component is present only in commented JSX. A saved advertisement is therefore not evidence of display on these pages.

/admin/home-components stores additional category/manual product sections for older home components. The current homepage uses SaraLanding, not that older configurable section pipeline. Use the Marketing Dashboard for its supported current sections.

The separate /offers page reads live merchandising records from /api/offers for Today's Deals, Mega Sale, Clearance and Store Exclusive shelves. The coupon form at /admin/promotions writes coupons, not those records. Do not assume its menu label connects the two.

Scope is an exact contextual match, not a customer segment. On /products, the first selected sub-category name wins; otherwise the first selected category name is used. Matching is case-insensitive and trims spaces. On product rails, use the brand/manufacturer name. If scoped matches exist they replace the unscoped list; otherwise blank-scope banners are used. Home, brands directory and cart have no scope context, so leave scope blank there.

Do not confuse these destinations

/products is the listing controlled by the Products & Offers tab and listing banners. The separate /offers hub uses offer shelves. A banner CTA can link to either, but placing a banner on one does not place it on the other.

Category/sub-category pages still use the older vector/uploaded hero system. A scoped listing banner is for a filter on /products, not automatically the dedicated category route.

3. How to create a poster for the current homepage

Use Banners & Promos, not the older Hero Posters page. This is the simplest route for artwork created in Canva, Figma, Photoshop or another design tool.

  1. Sign in with an authorized admin account. Open /admin/listing-banners.
  2. In New banner, choose a connected placement, for example Home - main poster carousel. Leave Scope blank for home.
  3. Write a short Title and Subtitle. Where available, set the handwritten note. Enter bullet points separated by commas; the form retains up to six, while the main hero displays up to four.
  4. Set Button text and Button link, for example Explore Diwali and /campaign/diwali-collection. Create and verify the destination first.
  5. Upload the artwork or enter an existing image URL. Choose gradient colours and, for a light background, enable Dark text. Inspect the live preview.
  6. Set Order. Smaller numbers display first. New banners start off. To keep a draft, leave On - visible on storefront unticked and click Add banner.
  7. After approval, switch the saved banner On, or edit it, tick On and click Save changes. Check that the relevant Marketing Dashboard section is also visible.
  8. Open the actual customer page on desktop and mobile, wait for the banner refresh or reload, and test its CTA. A generic admin preview is not a guarantee of the exact page layout.
Publishing and removal: an uploaded image alone does not publish a banner. Save the banner record and enable it. To end a campaign, switch its records Off; deleting is permanent. Banner forms do not expose start/end scheduling. Marketing content and banner data use refresh intervals, so do not assume all open customer tabs update instantly.

4. Vector poster types & built-in creation

Open /admin/posters. The library has 20 built-in SVG posters in five groups, four per group, plus custom posters you create.

FestivalGanesh Chaturthi, Diwali, Holi, NavratriSeasonal event awareness and links to curated collections.

Built-in copy is not automatically safe to publish. Some templates contain fixed store counts, maximum discounts, "free" benefits, warranty durations or "lowest price" claims. Validate every claim against live stock/pricing and approved terms. If the built-in wording is unsuitable, create a custom poster with accurate copy rather than publishing it unchanged.

Create a custom vector poster

  1. Click Create your own. Enter the small label, headline, second headline line, supporting line and button text.
  2. Choose a group. This is library organisation, not a targeting or scheduling rule.
  3. Optionally add a photo: PNG, JPG or WebP, no larger than the form's 5 MB limit.
  4. Choose one of five patterns: Rays, Dots, Grid, Waves or Arcs. Choose one of six colour presets or fine-tune From, Via, To, Accent and Ink.
  5. Inspect the actual SVG preview and click Save poster. This creates the artwork; it is not yet selected for display.
  6. In its library card, set Link to a page using a site-relative path. Optionally choose a product, category or sub-category under Show on this poster, then choose the item.
  7. Tick the poster and click Publish selection. Validate on a page that renders the older HeroSection, such as a real category page. It does not replace the current home main carousel.

Existing template: skip creation; choose its destination/optional featured item, tick it, then Publish selection. The catalogue selection UI is not a general drag-to-reorder tool.

Upload a completed photo/banner instead

  1. On the same page, go to Uploaded hero slides and click Upload slide.
  2. Choose a PNG/JPG/WebP photo, recommended 1920 x 600, within 5 MB. Add optional title/subtitle and CTA/link.
  3. Click Add uploaded slide. Use the visibility control and up/down arrows for enabled state and carousel order.
  4. In the older hero, selected vector posters take precedence over uploaded slides. To use uploaded slides, clear the vector selection and publish it. The older hero also retains its own campaign/fallback slide behaviour.

5. How to design poster artwork

Design outside the application

  1. Decide the objective and destination before designing: collection awareness, category browsing, coupon promotion or a store enquiry.
  2. Use your own or licensed product photos and brand assets. Build an appropriate canvas in your design tool.
  3. Keep one focal product/collection, a short headline and one CTA. Include eligibility/expiry wording where needed.
  4. Export artwork, upload it through the connected admin form and preview its crop at both narrow and wide widths.

For Banners & Promos, the app renders title, subtitle and CTA separately from the image. A clean product image often works better than baking the same text/button into the image twice.

Dimensions & limits

Vector poster: generated SVG is 1920 x 600 (16:5). The SVG creator is an artwork builder, not a full multi-layer design editor.

Uploaded older hero slide: form recommends 1920 x 600; PNG/JPG/WebP, up to 5 MB.

Landing-page banner: form recommends 1920 x 400; client accepts images up to 5 MB.

Banners & Promos: no single fixed canvas size fits all placements. Its upload endpoint limits each file to 15 MB. As a design recommendation, use compressed WebP/JPG, keep important content away from edges and aim well below the upload limit.

Suggested safe example: label "DIWALI COLLECTION"; headline "Light up your home"; supporting text "Explore TVs and appliances. Product prices and terms apply."; CTA "Explore collection"; destination /campaign/diwali-collection. This describes a collection without inventing a discount, delivery promise or bank entitlement.

6. Create the campaign destination page

Use /admin/campaign-pages when your poster should open a dedicated collection rather than a general catalogue.

  1. Click Create Campaign. Enter a campaign name, for example Diwali Collection.
  2. Review the auto-generated URL Slug, for example diwali-collection. Its destination is /campaign/diwali-collection.
  3. Upload the hero banner, recommended 1920 x 400. Select the curated products using the search and selection controls.
  4. Review Campaign Active status; it starts checked in a new form. Untick it if you want an inactive saved page. Save with Create Campaign or Update Campaign.
  5. Verify the public URL. Only active campaigns are returned publicly; missing or inactive ones return a not-found state. The page shows its hero and featured-product grid; with no products it shows a Coming Soon state.
  6. Set your storefront banner's button link to this URL. Separately add the full website URL to your customer message.

The landing-page form has no start/end scheduling controls. Active state is separate from a theme's scheduled dates. Products and commercial terms still need validation; artwork does not alter the authoritative cart price.

7. Send the campaign to customers

Storefront posters are seen by visitors. Customer campaigns reach a selected audience. The message library currently contains 54 campaigns: 13 lifecycle, 28 festival and 13 promotion, with 28 audience filters. These counts are independent of the 20 vector posters.

  1. Choose campaign
  2. Edit message
  3. Select opted-in recipients
  4. Review final preview
  5. Explicit send or dry-run

Email

  1. Open /admin/customer-centric and choose a template matching your objective.
  2. Review the subject and message HTML. Add your landing-page URL using the real public website origin, not a relative path that an email client cannot resolve. Use absolute, publicly accessible image URLs; this guide's local screenshot paths are not email assets.
  3. Click Choose Recipients, apply the relevant audience filters and select eligible, opted-in recipients. Check the actual count; segments are filters, not a promise that every registered customer has consent.
  4. Click Preview & Send. Review the final email and recipients. Only use the final send action after authorized test delivery, commercial approval and consent checks.

WhatsApp & automated reminders

Select the WhatsApp channel and use Preview (dry run) to inspect its plan. There is a separate backend send path; this UI screenshot does not prove that a provider is configured, approved or delivering messages.

Abandoned-cart, wishlist, repeat-purchase and win-back templates can support retention marketing, but a saved template does not create an automated journey. Scheduled execution, eligibility, consent and provider delivery must be configured and verified separately.

For all campaign types, audiences and retention flows, see the existing Marketing Campaign Types & Customer Flows guide.

9. Before you publish

Display & artwork

  • Correct connected placement, correct contextual scope, correct order and active state.
  • Marketing Dashboard parent section is visible; image loads and text is readable.
  • Desktop and mobile crop, CTA destination, keyboard access and sufficient contrast checked.
  • Verify first-two/first-three limits; turning something on does not guarantee it makes the visible cut.
  • Inspect the actual storefront, not only the generic admin preview.

Commercial & customer safety

  • Approved prices, stock, discounts, expiry, warranty, delivery and EMI terms.
  • No unsupported "free", "lowest", maximum saving or store-count claims.
  • Channel-specific consent, working unsubscribe and authorized test delivery.
  • Real provider credentials and scheduled execution verified before claiming delivery/automation.
  • Named owner for publishing, ending the campaign and handling customer enquiries.
This guide does not change the production verdict. Screenshots and source inspection establish controls and intended wiring, not hosted provider delivery or launch readiness. See the production-readiness audit and customer-journey audit for the remaining release gates.
