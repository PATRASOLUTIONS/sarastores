Before submitting: category Marketing, language English (en), body only, six positional variables. The app currently sends body components; these designs use text links. The tinted chat frame is a preview, not a configurable WhatsApp background.

Data mapped to each message

VariableApp data
{{1}}Customer first name
{{2}}Current catalogue product name
{{3}}Current server-quoted INR unit price
{{4}}First touch: contextual reminder; later touches: verified offer information
{{5}}First touch: safety/availability; later touches: confirmed deadline or no-deadline wording
{{6}}Tracked product URL followed by signed unsubscribe URL
Timing begins at cart activity or the failed payment. Quiet hours and minimum gaps can defer delivery. New matching orders stop reminders. Offer deadlines appear only when verified. Template approval and messaging opt-in are required. No provider submission or customer send has occurred.
